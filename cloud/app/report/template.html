Method

{% for plan in data.plans %}

Each test of the plan restored up to {{ plan.mail }} mail{{ "" if plan.mail == 1 else "s" }}, {{ plan.sp }} SharePoint file{{ "" if plan.sp == 1 else "s" }} and {{ plan.od }} OneDrive file{{ "" if plan.od == 1 else "s" }} from one restore point of the backup.

{% else %}

The items of a test are a sample: canary items seeded in the tenant for this purpose, whose content is known in advance, plus items chosen at random from the backup's own listing. Each item was restored into a restore target set aside for testing (the restoretest mailbox, the RestoreTarget library or the RestoreTarget OneDrive folder), read back through Microsoft Graph, compared, and removed from the target. A canary is compared by the SHA-256 of its content; a random mail by its subject, received time and sender; a random file by its name and size.

Verification levels covered: 1, 2, 3; level 4 partially (files opened and read via Microsoft Graph).
