Method

{% for plan in data.plans %}

Each test of the plan samples up to {{ plan.mail }} mail{{ "" if plan.mail == 1 else "s" }}, {{ plan.sp }} SharePoint file{{ "" if plan.sp == 1 else "s" }} and {{ plan.od }} OneDrive file{{ "" if plan.od == 1 else "s" }} from one restore point of the backup.

{% else %}

No test of a plan has a result in this period.

{% endfor %}

The items of a test are a sample: canary items seeded in the tenant for this purpose, whose content is known in advance, plus items chosen at random from the backup's own listing. A test restores each item into a restore target set aside for testing (the restoretest mailbox, the RestoreTarget library or the RestoreTarget OneDrive folder), reads it back through Microsoft Graph, compares it, and removes it from the target afterwards. A canary is compared by the SHA-256 of its content; a random mail by its subject and received time, and by its sender's name when the backup lists one; a random file by its name and, unless it is an Office document, its size.
